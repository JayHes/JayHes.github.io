Unreal Engine
Game Workshop 2

A university game-development curriculum designed to make Unreal Engine easier to follow through clear explanations, screenshots, practical examples, and two distinct delivery formats.

Project Overview

I designed learning material for a university summer game-development program and structured it so the same Unreal Engine concepts could work in two settings: live classroom instruction and independent student study.

My Role

Curriculum design, technical instruction, visual learning materials, screenshots, lesson structure, and supporting the instructor so the material could continue to be delivered independently.

Design Goal

Reduce confusion for beginners by pairing technical explanations with visual references instead of asking learners to rely on text alone.

One curriculum, two delivery formats.

Both versions use screenshots and visual examples throughout. The difference is how the material is meant to be used.

Live Classroom

Instructor-Led Presentation

A more visually styled format designed to be projected while an instructor leads the class through each concept.

 Independent Study

Self-Guided Course Guide

A calmer, more detailed reference format designed for students to read and follow at their own pace.

Same lesson, different delivery.

The Outliner lesson shows how the same core teaching content was adapted for different learning contexts without removing the visual support.
